# Contributing

Thank you for your interest in LUMEN / LVS.

## Before contributing

1. Open an issue describing the proposed change.
2. Keep changes focused and reproducible.
3. Preserve third-party license and attribution information.
4. Do not add secrets, credentials or private datasets.
5. Include tests or validation where practical.

## Rights metadata

Project-originated files should include or reference:

- `rights_holder: Wolfgang Netik`
- `Copyright © 2026 Wolfgang Netik`

Third-party rights must not be replaced.

## Pull requests

A pull request should explain:

- what changed
- why it is useful
- whether dependencies changed
- whether rights / licenses changed
- how the change was tested
